# Portafolio web | Johanna Vásquez

Sitio personal de QA Engineer Jr. con evidencias enlazadas a GitHub.

## Resumen

Presento mis áreas de trabajo en testing manual, API y automatización. La web está desarrollada en HTML5, CSS3 y JavaScript, sin frameworks.

## Alcance

- Presentación en primera persona con fotografía profesional.
- Seis casos de trabajo enlazados a cinco repositorios QA.
- Filtros interactivos por tipo de prueba y un bloque de resultados de DummyJSON.
- Experiencia profesional previa, herramientas, metodología y contacto.

## Herramientas

`HTML5` · `CSS3` · `JavaScript` · `GitHub Pages` · `Node.js` (comprobaciones locales)

## Cómo ejecutar o revisar

Abre `index.html` en Chrome o Firefox. También puedes publicar la carpeta en GitHub Pages desde la raíz de la rama principal. No requiere instalaciones ni servidores.

Para ejecutar las comprobaciones locales (opcionales):

```bash
node checks/portfolio.test.mjs
python checks/check_markup.py
```

## Limitaciones

Los números de pruebas representan resultados históricos, no datos actualizados automáticamente. Algunas aplicaciones de práctica ya no están disponibles, por lo que el enlace conduce a la evidencia en GitHub y no a una demo en vivo. El sitio no envía formularios ni recoge datos de usuario.
