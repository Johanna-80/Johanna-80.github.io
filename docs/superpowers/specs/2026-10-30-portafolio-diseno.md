# Portafolio QA de Johanna — diseño aprobado

## Objetivo
Crear una versión final presentable en clase de un portafolio HTML estático para Johanna Vásquez, QA Engineer Jr., con vínculos específicos a evidencias públicas reales.

## Enfoque elegido
Evolución del diseño blanco/negro/morado existente (opción A), con toques de paneles técnicos oscuros de la opción B. Se conservan foto profesional, trayectoria, formación, contacto y sitio GitHub Pages actual. Entrega local ZIP sin publicar automáticamente.

## Contenido y comportamiento
- Hero: propuesta de valor honesta, enlaces a los trabajos y contacto, métrica verificable.
- Panel técnico de DummyJSON con `19/19` pruebas aprobadas en ejecución del 30/10/2026 y enlace directo al workflow. La referencia es histórica, no un monitor en tiempo real.
- Seis casos visibles: DummyJSON, Urban Scooter, Urban Routes UI Automation, Urban Grocers API, Urban Routes manual y técnicas de diseño. Cinco repositorios de QA públicos (la documentación manual comparte el repositorio Portafolio-QA).
- Filtros accesibles Todos, Manual, API, Automatización; un conteo que se actualiza y opción Todos restablece los seis casos.
- En cada caso contexto breve, herramientas, hallazgo/resultado honesto y enlace específico de GitHub. No se atribuyen métricas no verificadas ni se confunden las respuestas de DummyJSON con persistencia de datos.
- Sección «Cómo trabajo» (requisitos, diseño, ejecución, reporte y seguimiento).
- CSS responsive de calidad y preferencias de movimiento reducido; comportamiento JS progresivo, con contenido disponible sin JS.
- Un solo `index.html` con estilos y script integrados, carpeta `assets/img`, comprobación automatizada sin dependencias y guía de publicación.
